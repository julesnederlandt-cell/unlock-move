# UNLOCK Move 🏃

Android prototype for step counting, estimated distance and estimated calories.

## Easiest setup
This ZIP is arranged so you can upload the ZIP file itself to a GitHub repository as a downloadable project file. **GitHub will not unpack it into repository source files automatically.** To build the APK from source, the files need to exist in the repository, or you can use the included GitHub Actions workflow after the source files have been uploaded normally.

## Features
- Step counter sensor when available.
- Accelerometer fallback estimate.
- Distance estimate from stride length.
- Approximate calories based on weight and distance.
- Local settings only.

## Important
This is an early source-code prototype, not a prebuilt APK. Tracking is not yet reliable while the app is in the background. Calories and distance are estimates.
